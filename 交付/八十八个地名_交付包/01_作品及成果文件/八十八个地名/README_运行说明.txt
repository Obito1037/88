八十八个地名——一根竹竿上的淮海支前路
交付审核版 v1.0 | 2026-10-22

一、打开作品
完整解压文件夹，在 Chrome 或 Edge 中双击 index.html。所有运行资源位于本地，不需要安装、不需要本地服务器、不需要网络。
开始页点击“开始体验”，完整阅读建议 6–8 分钟；点击“评审快览”约3分钟自动演示。index.html?demo=1 会突出快览入口，仍需要一次点击解锁浏览器声音。
如本机把HTML文件关联到其他编辑器，请右键 index.html > 打开方式 > Microsoft Edge 或 Google Chrome。

二、操作
刻：按住竹竿、按钮或空格，约2.9秒刻完；松手保留进度。“点击刻完”可替代。
推：按住按钮、路线或右方向键，约28秒走完5个名称；也可横向拖动或点击走完。
一起推：先推一下，再点“一起推”，12只手加入；键盘可依次按 A、L，也可直接点击一起推。
读：拖动侧光滑块，移动指针，或方向键选择名称；点名称打开来源。“点击读完”可替代。
数：点击按钮或滚轮逐批汇入；“点击展开全部”显示543个点。减少动效不减少统计点数。
留：输入不超过8个Unicode字的地名，选取一句固定致敬语，点击生成，再点“下载海报 PNG”。图片为1080×1920纯Canvas绘制。
每幕可点击“跳过 / 下一幕”；Esc 同样可跳过。底部竹竿目录可跳转全部9段。每幕15秒无操作显示明确提示。
所有按钮可使用 Tab 聚焦和回车激活。声音、字幕可切换。演示可暂停或转为自由体验。来源弹窗使用 Esc 关闭。

三、审核状态与素材属性
本版可运行、可阅读、可生成海报；史料仍待团队人工打开原文、核对及截图。团队尚未完成竹竿实拍、真人配音、图像后期和最终文案审核。本版不得描述为团队已完成上述亲手工作，也不等同于报名材料全部齐备。
4幅背景为OpenAI ImageGen生成的木刻艺术示意，均有显式标识，非文物照片、历史现场或真实人物写实画像。
文字、代码与程序图形由OpenAI Codex辅助。声音是Web Audio程序合成的操作提示，无真人配音；旁白作为可读文字保留。真人录音的音画同步需后续另行验收。
名称选自人民日报报道的列举，含出发地，共10个。非完整清单、非准确路线，濉溪口不被认定为全部行程终点。侧光界面非原件复原。
“第八十九个地名”为当代致敬创作，不增补历史文物。路线示意，非地图。

四、文件和内容维护
js/content.js：九段文案、事实条目、来源编号和固定致敬语。
js/sources.js：来源机构、标题、日期、链接、摘录与核验状态。
js/assets.js：图像和程序合成声音的来源属性。
js/app.js：场景、交互、离线海报、音效及来源层。
css/style.css：响应布局与视觉样式。
css/fonts.css：本地内嵌子集字体；未覆盖的任意地名使用系统字体回退。
assets/img：4幅AI生成艺术示意WebP。licenses：字体许可证。
修改内容后请重新执行交付包中的验收清单。不能把待核验状态直接改为通过，必须先有人工核验记录。

五、数据与网络
运行期间不发起网络请求，不用fetch、XHR或ES Module，不使用Cookie、本地持久存储或统计服务。输入只存在页面内存，关闭页面即清除。原文链接需主动点击才会打开外部页面；离线时可阅读本地摘录。
海报不绘制任何file://外部图片，避免Canvas跨源污染。输入地名不会写入文件名或上传。

六、技术验证接口
window.APP.getState() 读取当前幕和交互状态。
window.APP.goTo(0..8) 跳转场景。
window.APP.start(true/false) 进入自动演示/自由体验。
window.APP.setDemoInterval(毫秒) 用于自动化测试缩短每幕时长，正常默认为20000毫秒，总计180秒。
此接口不包含网络或系统访问能力。
