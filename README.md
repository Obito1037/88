# 八十八个地名

**审核版交互网页**｜一根竹竿上的淮海支前路

作品以唐和恩支前竹竿为叙事线索，通过“刻、推、一起推、读、数、留”六个核心交互，呈现支前史料和当代致敬。九段叙事的建议完整体验时长为7分20秒；自由浏览时长取决于操作。

当前版本供体验、内容核验与团队修改。84项浏览器自动检查已通过（28项基础检查＋56项补充检查），但尚无团队人工史料核验、实拍竹竿、真人旁白、团队后期与同学试玩的完成记录。本仓库不表示赛事已经提交或团队审核已经通过。

## 直接运行

下载仓库ZIP并完整解压，在桌面版Chrome或Edge中双击：

```text
交付/八十八个地名_交付包/01_作品及成果文件/八十八个地名/index.html
```

网页采用本地经典脚本，运行不需要Node.js、Python、服务器或联网。图片和字体随站点提供。查看引用原文需要网络；离线仍可阅读本地来源说明。

- 点击开始后体验；六个核心交互提供按钮、触屏或键盘操作。
- 可通过场景导航跳转、跳过当前场景、查看史料和使用评审快览。
- 海报由Canvas在本机生成。输入仅用于当前页面，不上传、不持久保存。
- 音效由Web Audio API程序合成；当前没有真人配音，旁白文字以字幕呈现。

具体功能状态和实测证据以交付目录中随版本提供的检查记录为准。运行遇到问题时，请记录浏览器版本、操作步骤及截图。

## 内容边界

本作选用《人民日报》报道列举的10个名称，含出发地。这些名称不是完整88地名清单，路线连接只是阅读示意，不能据此认定精确路径或全部行程终点。

“543万人次”使用明确采用该单位的来源；543个光点每点表示1万人次，不对应独立个人名单。“第八十九个地名”是当代致敬创作，不增补历史文物。收藏地等冲突在史料层保留，不编造真实人物对白或心理活动。

## 修改与流程复现

以下开发命令需要自行准备Python 3或Node.js；浏览器体验不需要这些开发环境。

修改场景文字用`js/content.js`，修改证据用`js/sources.js`，修改素材登记用`js/assets.js`。网页以这些JS文件为运行依据；同步更新工作记录中的JSON镜像及相应文档。核验状态应按真实进展填写，不直接批量改为“通过”。

静态内容检查：

```shell
node tools/prepare_qa.cjs
```

检查覆盖场景数量、时长、旁白长度、引用编号和图像存在性等；不能替代浏览器操作实测或人工史料核验。

需要重建字体时，在仓库根目录依次运行：

```shell
python -m pip install --target tools/python_packages "fonttools[woff]" brotli
python tools/download_dependencies.py
python tools/build_fonts.py
```

下载脚本从字体官方仓库取得源文件与许可，并写入文件哈希；字体构建脚本按站点文案制作WOFF2子集并内嵌到`css/fonts.css`。新增文案后应重建；任意用户地名使用系统字体回退。该下载流程需要联网，上游分支内容可能变化，重新构建时请保留实际来源与哈希。

`tools/download_browser.py`用于下载本项目自动检查使用的Windows浏览器，不是体验网页的前置条件。自动检查和文档构建的环境要求以相应脚本为准。

重建PDF需要安装`reportlab`、`pypdf`和`Pillow`，先运行上述字体下载脚本恢复官方OFL字体`工作记录/字体原始/LXGWWenKai-Regular.ttf`，再运行`python tools/build_documents.py`。生成器读取交付包内已脱敏的图像生成记录。`python tools/render_documents.py`用Poppler渲染复核；可将`pdftoppm`加入PATH，或用`PDFTOPPM`环境变量指定可执行文件。
